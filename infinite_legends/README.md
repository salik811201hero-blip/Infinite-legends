# Pokémon: Infinite Legends — Version 0.1

This folder contains original project content for the Aetheria fan-game project.
The repository is based on pokeemerald-expansion; the upstream engine is retained
as a separate foundation and should not be overwritten.

## First playable milestone

The first playable slice will contain:

1. New-game opening and player setup
2. Lumenport Town
3. Professor introduction and starter choice
4. A short first route with wild encounters
5. A rival battle
6. Save/load verification

## Development rules

- Keep upstream engine files intact wherever possible.
- Add original maps, scripts, data, and graphics in isolated project paths.
- Use assets that are original, licensed, or otherwise permitted for this fan project.
- Do not copy compiled ROM content or proprietary decompilation assets.
- A source-code commit is not a playable ROM. The project must be built and tested
  with the documented toolchain before a release is called playable.

## Current status

Planning and engine inspection. No Aetheria map or playable ROM has been built yet.
